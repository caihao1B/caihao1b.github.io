个人主页 / 项目概述

从任务决策，到在线执行

路径规划给出“怎样走”，任务调度决定“谁去做、何时返回、如何继续”，执行层接收计划并处理真实反馈。三个项目围绕这条链路展开，各自说明已验证的结果与系统边界。

PROJECT 02 · COMPLETED SIMULATION

母车与农田机器人协同调度

本项目已实现一台运载母车与三台作业机器人的任务闭环：沿道路运输、依次卸载、领取田间条带、作业与资源检查、返航排队补给、从断点继续，以及全员装车后返仓。

Agent 分别保存位置、资源、任务和状态。Java 核心使用规则与贪心条带分配，有限状态机推进执行；独立的入口通道、装卸坡道与补给工位约束共享资源。

完整展示页将真实运行记录同步映射到地图、调度树和 Agent 状态机。调度树是对代码分支的行为树式解释，页面会给出对应条件、动作与源码位置。

PROJECT 03

ROS 2 移动机器人覆盖任务在线执行

项目以 ROS 2、Gazebo 和 Nav2 为执行基础，将离线计划表示为可管理的分段覆盖任务。任务层监督执行状态，在动态障碍和进度异常下进行等待、局部恢复及剩余任务调整。

其核心是离线计划与在线执行之间的接口，以及未完成区域的显式记录。项目 01 的网页动画只是参考轨迹回放，不替代本项目中的 ROS 仿真与系统运行证据。

项目 02 提供了 ROS 2 计划适配器，作为后续结合的接口基础：它消费冻结几何计划，等待部署和回收确认。当前交付没有建立 Java 调度状态与 ROS 2 机器人反馈之间的完整实时闭环。

演示材料待独立整理：版本对应的 Gazebo 视频、行为树执行记录、覆盖统计与失败案例。规划中的机械臂与点云扩展没有列为已完成成果。
