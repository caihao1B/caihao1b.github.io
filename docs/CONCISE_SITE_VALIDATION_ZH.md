## 浏览器测试环境及边界

测试环境的Chromium企业策略禁止URL导航，因此未更改策略，也未使用绕过策略的参数。浏览器检查使用 `tools/browser_smoke.py --inline`：读取本站原有HTML、CSS、JS和媒体，将其内嵌到Chromium文档，再实际运行脚本和交互。独立使用Python HTTP客户端验证预览服务器路径和响应。

这证明本次受测文档、Canvas/SVG、媒体元数据和交互在Chromium内运行正常，不等于已经验证Windows本地App、浏览器HTTP导航、GitHub Pages发布、所有浏览器或所有触摸操作。

桌面/手机宽度截图位于 `reports/screenshots/`。已视觉检查首页及两个项目页的桌面截图、两个项目页的手机截图。手机检查是桌面Chromium视口模拟，不是实体手机测试。

没有重新执行Java仿真，也没有新验证ROS 2、AnyLogic或实车。原工程与旧版网页报告保留供追溯，不能视作本次新功能的测试。

## 自己复查

基础检查，无第三方依赖：

```powershell
py -3 tools/check_site.py
```

可选浏览器检查，需要在自己的环境安装Playwright及其浏览器后执行，安装前应由你明确同意：

```powershell
py -3 preview_server.py
# 在另一个终端运行；以服务器实际输出端口为准。
py -3 tools/browser_smoke.py --base-url http://127.0.0.1:8000
```

只浏览或修改网站不需要安装Playwright。手动预览同样重要，尤其要在发布后检查资源路径、手机效果和邮箱等公开内容。
